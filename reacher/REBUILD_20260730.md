## Specs for the components that must be re-authored

**`train_window.py`** — 3-frame window quasimetric. Stack rows
`[z_{t-2L}, z_{t-L}, z_t]` (L = `--lag` = action_block = 5) from an fs1 cache,
episode starts clamp to the earliest row; train with the canonical TD recipe
(`quasimetric` head, hidden 256, depth 2, embed 128, expectile 0.1, n-step 50,
gamma 1.0, 6000 steps, batch 1024, p_cross 0.3, balanced); `save_metric(...,
"td", 3*D, {..., "window_frames":3, "window_lag":5})` so the eval hook infers
`_m=3`. Print the tiled-goal diagnostic (deploy-style tiled goal vs data-window
goal; measured 6.9 vs random-pair 82.2 = benign).

**`make_l2window.py`** — adds an `l2` learner to `trm/io.py`: `L2WindowCost`,
parameter-free, `latent_dim=3*D`, `cost = ||x-y||` over the stacked window,
gradient-safe; save a 576-d blob to `metrics/l2window3.pt`. This is the
*unlearned* window arm (Latent+CEM-window).

**pad-context** (`--pad-context` in `train_lip_ac.py`) — after the replay merge,
collapse the training context to the deployed 1-frame form:
`zh = zh[:, -1:].expand_as(zh).contiguous(); ah = torch.zeros_like(ah)`.
Worth ~+5 held on the terminal critic.

**oracle** (`trm/oracle.py` + an `oracle` branch in `_build_inner`) —
`OracleQPosCost`, readout to (sin,cos) per joint, cost = worst-joint wrapped
angular error, `latent_dim=D`. Fit with `fit_oracle_readout.py` (ridge, MLP
fallback; achieved 0.0045 rad = 9% of tolerance). Only needed to re-run the
ceiling test.

**eval drivers** — all follow one shape: `eval_wm.py --config-name reacher
policy=<wm> eval.dataset_name=$CANON dataset.stats=$CANON
+eval.ep_range=8000:10000 seed=<42..47> eval.goal_offset_steps=25
eval.eval_budget=50 solver.batch_size=10 <solver args>`, parse
`HELD-at-end` / `ever-in-ball` from `[success-convention]`, append
`name,held=..,latched=..` to a CSV, card = mean over 6 eval seeds. **No
`history_len`, no `use_frame_history`** (1-frame is THE config; a `[hist-inject]`
line disqualifies a cell).

## Traps that cost time before (do not re-learn)

- `pgrep -f <name>` over ssh **matches your own ssh command line** — verify a
  launch by the log file appearing, never by pgrep. Cost 4.5 idle GPU-hours.
- The trainer writes `weights_epoch_N.pt` and no `weights.pt`; the loader
  refuses ambiguous dirs. Normalise **in the driver** (fixed by hand once, so it
  recurred).
- Fine-tune configs: the trainer saves the TRAINING config as `config.json`;
  planners need the ARCHITECTURE config — copy the base's over it.
- Dyna mixes must exclude eval episodes: the r1 mix leaked 400k rows (10.1%)
  from 8000:10000.
- One EGL renderer per GPU; a 4th concurrent process SIGABRTs.
- Nested heredocs over ssh break constantly — write scripts locally and `scp`.
